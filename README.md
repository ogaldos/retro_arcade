# ASTRO ARCADE MULTIVERSO

Colección de juegos arcade retro espaciales en HTML5 Canvas + JavaScript puro (sin dependencias externas ni paso de compilación; sprites pixel-art y audio chiptune generados por código).

## Versiones incluidas

Abre `index.html` para acceder al **Selector de Versiones** con vistas previas animadas en vivo:

1. **Versión 1 — ASTRO PIXEL STORM** (`astro_pixel_storm.html`)
   - Formato panorámico 960×600, Interceptor clásico, Bomba Nova, sistema de combos y Estación Jefe Kronos.
2. **Versión 2 — ASTRO VANGUARDIA** (`variante_juego_01/ai_studio_code.html`)
   - Cabina arcade vertical 3:4, barra de escudo HP, planetas pixel-art AI/ML & GEN AI con dithering Bayer y Estación Dreadnought.
3. **Versión 3 — ASTRO COSMOS ULTRA** (`variante_juego_02/index.html`)
   - Combina los assets de V1 y V2 con 4 naves seleccionables en hangar, 10 tipos de enemigos, 3 megajefes rotativos (incluido el Titán Robótico Cósmico Hyperion), Hiper-Carga, drones escolta, galería de assets y fondos cósmicos en 5 capas con soles, nebulosas, planetas, estaciones espaciales y robots cósmicos.
4. **Versión 4 — NEBULA CITADEL ZERO** (`variante_juego_03/index.html`)
   - Edición táctica progresiva con 3 naves nuevas con habilidad propia (`[E]` Pulso PEM, Escudo Aegis o Salto de Fase), 7 enemigos inéditos desbloqueados gradualmente oleada a oleada, 3 nuevos megajefes de 2 fases (*Solaris-IX*, *Kraken-0* y *Omega-Prime*), fondos con agujero negro, astilleros y guardianes de jade, y power-ups más limitados pero variados y decisivos (incluyendo salvas de misiles teledirigidos).

## Cómo ejecutar

- **Online (GitHub Pages):** https://ogaldos.github.io/retro_arcade/
- **Directamente en el navegador:** haz doble clic en `index.html`.
- **Con servidor local:**
  ```bash
  python -m http.server 8000
  ```
  y abre `http://localhost:8000/`.
